# AI Business Insight System

Prototyp aplikacji analitycznej stworzonej na potrzeby pracy magisterskiej.

Celem projektu jest analiza danych sprzedażowych oraz tekstowych z wykorzystaniem metod sztucznej inteligencji w celu wspierania procesów decyzyjnych przedsiębiorstwa.

## Technologie

- Python
- Streamlit
- Pandas
- NumPy
- Plotly
- Scikit-learn

## Uruchomienie projektu

```bash
python -m venv .venv
.venv\Scripts\Activate.ps1
pip install -r requirements.txt
streamlit run app.py
